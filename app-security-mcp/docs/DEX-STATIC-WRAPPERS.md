# Android 静态包装方法返回值传播（0.25.0）

扩展同 DEX 的静态无参 String 返回值摘要：叶子仍是固定字符串后直接返回；包装方法忽略 nop 后必须恰好为无参 invoke-static（或 range）、move-result-object 和返回同一寄存器的 return-object。按完整类、方法、原型匹配，先收集再解析，不依赖文件中顺序。

最多支持 4 层包装方法加 1 个叶子，摘要总量上限仍为 10000。解析时检查访问过的方法，递归环、缺失或不支持目标、超过深度均不可传播。调用方原有的其他寄存器仍保守清除。

证据新增 return_chain 和 wrapper_depth，逐层含方法身份、包装调用及返回位置，末层包含常量位置；不保留原值。constant_method_summaries_unresolved 统计已收集但无法求解的摘要，不是所有不支持的方法数。候选仍为 candidate，不确认运行行为、类初始化、异常或实际认证用途。

不支持跨 DEX、参数传递、实例方法、分支、带额外操作的包装、递归和完整调用图。static-deep 仍未自动执行完整深度分析。

## 验收

真实 Java→D8→DEX 集成测试验证 1 层和 4 层包装后的字段候选，并检查链长度、叶子方法和每层指令位置；5 层、互递归和夹带其他调用的方法不生成该字段候选。保留同名重载、分支与实例方法反例。

独立单元测试验证倒序输入、4/5 层边界、循环、缺失目标、返回寄存器不匹配及叶子深度为零。插件包严格回归 37 项通过、零跳过。

已安装0.25.0，Codex发现3个Skill、21个工具。实际复扫用户APK：1个DEX、22711方法，0个可解析摘要、0次传播、1个已收集但未解析摘要、0候选，整体partial。该未解析摘要不推断为固定值；未检出不是完整安全结论。证据 artifacts/validation/static-wrappers-real-apk.json。
