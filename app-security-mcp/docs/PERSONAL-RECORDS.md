# HC-011 明文联系人记录基础检测（0.12.0）

支持 Android/iOS 包内已解析 JSON 和 plist（包括二进制 plist）。同一个对象中必须同时出现明确姓名字段和支持格式的邮箱或电话字段，才产生候选。不跨对象、父子层级或数组记录拼接关系，不把单独邮箱/电话当作个人记录。

字段白名单支持 full_name、real_name、contact_name、customer_name、姓名、联系人姓名、客户姓名；邮箱与电话字段见 workers/personal_records.py。通用 name 不参与姓名识别，避免把包名、组件名和邮箱拼成个人信息。电话仅识别带 + 前缀的有限国际号码形状，不验证国家号分配、号码归属或真实可用性。邮箱也只是受限语法检查，不查询 DNS 或发送邮件。

排除已知占位姓名、模板值、示例邮箱域名、部分明显占位号码；不能自动识别所有合成样本，匹配不证明数据是真实个人信息。公开业务联系人也可能命中，需结合发行用途核实。

报告只保存文件/节点位置、成员摘要、固定 data_categories 和 record_authenticity=unknown，不保存记录的姓名、邮箱或电话。建议核实后移除误打包真实数据、采用明确合成样本、按业务需要受认证地获取最小数据，并复查构建输入和旧发行包；改字段名或混淆不能代替处理数据暴露。
