# HC-009 固定字符串比较分支基础检测（0.14.0）

本步实现 Android DEX 的有限认证判断候选，不能等同于后门识别完成。

## 检测条件

方法名称仅限 check/verify/validate/authenticate 加 password/pin/otp/passcode/verificationcode（忽略大小写和下划线）。名称只用于筛选，不证明业务用途。

从实际 DEX 方法的 registers/ins 元数据确定参数寄存器，仅跟踪入口处的常量字符串和对象移动。要求 String.equals(Object) 的一侧为常量字符串，另一侧源自参数；比较结果经过 move-result 后直接控制唯一向前的 if-eqz/if-nez 分支，目标必须为方法内已解析指令。不允许推断跨循环、switch、异常处理、其他条件分支、未知调用或覆盖。

记录比较位置、分支位置和目标偏移、成员摘要、方法/原型和字符串池索引，不输出字符串值。security_purpose=unknown，comparison_result_controls_branch=true 仅表示静态比较结果与分支有关。成功/拒绝方向、分支两侧行为、调用链、输入来源的业务意义、可达性和服务端校验均未确认。

修复建议要求先核实是否真是认证/授权的固定通用口令；确认后移除相应入口并落实受信端校验，再验证合法与非法输入及旧版兼容。普通字符串比较不是后门，改方法名或候选消失不证明修复。

- 实际 JDK/D8 编译的 checkPassword 与 verifyPin 正例命中，常量在比较左/右两侧均验证。
- 普通主题比较、前置条件分支、比较结果被覆盖、仅返回比较结果反例未命中。
- 独立边界测试：非参数、回跳、额外条件、goto、寄存器覆盖、未知调用均停止模式判断；证据不含常量值。
